# TWICE-DA: A Hybrid Transformer-CNN Architecture with Multi-Scale Deformable Attention

TWICE-DA is a **lightweight hybrid architecture** that combines the strengths of CNNs and Transformers.  
It is designed as a **universal visual feature extractor** for a wide range of computer vision tasks.  

This repository currently includes code and models for the following tasks:  
>Image Classification: Included in this repo. See **[here](https://github.com/rrotyrba/TWICE-DA/tree/main/twice_da)**

>Semantic Segmentation: Included in this repo. See **[here](https://github.com/rrotyrba/TWICE-DA/tree/main/segtwice)**

>Change Detection: Included in this repo. See here
